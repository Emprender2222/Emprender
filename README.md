# Emprender

App para emprendedores: pedidos, stock, finanzas, proveedores, metas, calendario e historial.

## Requisitos

- Node.js 18 o superior

## Cómo correrla

```bash
npm install
npm run dev
```

Abrí la URL que muestra la terminal (por defecto http://localhost:5173).

## Compilar para producción

```bash
npm run build
npm run preview
```

## Estructura

```
Emprender-app/
├─ index.html
├─ package.json
├─ vite.config.js
└─ src/
   ├─ main.jsx      → punto de entrada
   └─ App.jsx        → toda la aplicación
```
